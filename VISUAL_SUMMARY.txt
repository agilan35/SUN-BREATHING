🔄 VERIFICATION WORKFLOW
────────────────────────────────────────────────────────────────────────────

User uploads image
     ↓
File validation (type, size)
     ↓
Visual Inspection (OpenCV)
  → Blur check, artifact detection, pixel analysis, etc.
  → Result: Visual score 0-100, flags
     ↓
OCR Text Extraction
  → Read text, extract identifiers
  → Result: Extracted text, structured data
     ↓
Database Query (SQLite)
  → Search for certificates & documents
  → Similarity matching
  → Result: Match status, match score 0-100
     ↓
Verdict Calculation
  → Combine visual + text + match scores
  → Apply logic rules
  → Result: REAL / SUSPICIOUS / FAKE
     ↓
Log to Database
  → Store verification attempt
  → Keep audit trail
     ↓
Display Results
  → Show all analysis data
  → Display image preview
  → Show probability bars
